# 72FM — social image assets

Public, permanent hosting for 72FM's scheduled social posts (1080×1350 JPEG).

These images are published on 72FM's social channels; this repo exists only so
scheduling tools can fetch them from a stable URL that supports `HEAD` with a
correct `content-length` (Buffer requires this).

Raw URL pattern:
`https://raw.githubusercontent.com/AlonDrilich/72fm-assets/main/<filename>.jpg`

72FM — human-curated radio & playlists from 150+ countries. https://72fm.com
